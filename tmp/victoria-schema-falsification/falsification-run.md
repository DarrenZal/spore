# Victoria Schema-Falsification Run — Pass B + Pass C

## Headline verdict

The coherence-ready ingestion schema **survives the blind test directionally** — most
workshop content maps clean or near-clean, and far better than a triple store would (lenses,
per-object consent, derived-object inheritance, paper-map annotations, conditional commitments
all land). **But the blind/dynamic test surfaced six concrete gaps the static dogfood review
could not** — because pre-structured documents don't contain a live consent negotiation. All
six are **consent/visibility/commitment-shape** gaps, exactly where a real workshop differs
from a paper. None is conceptual-fatal; each is a bounded, namable schema change.

**This changes no claim-matrix row.** It strengthens the schema (a `safe` design proposal) and
directly improves the Mehul data-share schema before it ships. The schema correctly does **not**
try to adjudicate the one genuine value-clash (see U7) — it preserves both lenses + the
opposition edge for human review. The design principle ("surface candidate seams, don't
classify") held under test.

## Pass C — verdict against the four dogfood suspects

The static dogfood review pre-flagged four implementation-shaping suspects. Blind test result:

1. **Stakeholder / lens identity** → **RESOLVED (strong).** `Lens` handled all 8, incl. anonymized planner (U15) and mostly the role-refusing elder (U3). Minor: thin `role` enum (U2); no "self-described vs assigned" (U3).
2. **Commitment lifecycle** → **PARTIALLY confirmed.** Lifecycle states are fine (U16/U19/U22). Two real gaps: **bundle-/coherence-conditional** commitments (U17/G5) and **relational-not-transactional** marking (U18/G6).
3. **Map-geometry provenance** → **CONFIRMED needs work.** Paper-map annotation is clean (U5), but **protective obfuscation ≠ uncertainty** (U11/G1), **vernacular text-only locations** (U6/G7), and **temporal before/after** (U8/G8) are unhandled.
4. **Consent / governance boundary** → **CONFIRMED needs work — the sharpest findings.** Per-object cases are a genuine strength (U14/U15/U22). But three structures a *live consent negotiation* produces and a *document* does not: **category-level prohibition** (U13/G3), **acknowledged-withheld "locked door"** (U12/G4), and **inter-feature protective/masking relation** (U10/G2).

## The six gaps (concrete, namable schema changes)

- **G1 — Protective obfuscation field.** `MapFeature.obfuscation: {applied, reason, protects_feature_id}`, distinct from epistemic `uncertainty`. "Blurry on purpose to protect the adjacent midden" must not read as "low confidence."
- **G2 — Inter-feature protective relation.** A `TypedRelation` predicate (`shields` / `visibility_constrained_by`) or a `ConsentBoundary` that can reference a *neighbouring* protected object. Encodes "the busy public site camouflages the sensitive one."
- **G3 — Category-level / negative-space consent.** `ConsentBoundary.applies_to` a *type/category* + a `prohibit_creation` mode — "never create any feature for cedar-gathering sites," not just "mark this one private."
- **G4 — Acknowledged-withheld-knowledge marker.** A first-class "locked door": `DiscourseMove.move_type = withheld_marker` (content empty by design, status=withheld, + access protocol) or a small `WithheldKnowledgeMarker` object. The honest acknowledgment of a deliberate absence should not be faked via an empty content node.
- **G5 — Bundle-/coherence-conditional commitment.** A hyperedge constraint for "conditional on the joint state of a bundle," beyond per-commitment milestones. ("Fund it if the bundle stays coherent.") Thematically central to the coherence framing.
- **G6 — Relational-mode / fungibility flag on `Commitment`.** Mark "as a relationship, not a cheque" / "not a deliverable" so a downstream router never auto-commodifies a non-fungible commitment.

**Minor:** G7 vernacular text-only place reference (`MapFeature.descriptive_location`); G8 temporal before/after on `MapFeature`; thin `Lens.role` enum; a "contested site" convention binding multiple hyperedge-types to one `MapFeature` (U9).

## The "no data-entry" test

**Pass — with a caveat.** The schema is an *ingestion target*, not a live capture form, so the workshop is captured as messy scribe notes (exactly the Pass-A artifact) and extracted **post-hoc** — the room is never made to "speak schema." That's the right design and it keeps facilitation human.

**Caveat (real cost):** faithful extraction is **not mechanical**. The hard units (U9 creek-mouth hyperedge, U10 camouflage relation, U11 obfuscation, U17 bundle condition) require real interpretive judgment + steward review. The schema is *capture-compatible but extraction-expensive* — budget a skilled human (or strong model + steward sign-off), not an auto-extractor, for consent-laden workshop material.
