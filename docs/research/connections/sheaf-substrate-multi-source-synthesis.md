## §3 Sahely-unique contributions

Substrate Sahely brings that no other source in the existing Spore portfolio covers. Each is explicitly attributed.

### 3.1 [Sahely] Fano-plane closure-uniqueness derivation **(novel argumentative move)**

Sahely's argument is structurally different from Spore's existing primitive-admission discipline. Where Spore canon (per ADR-0048 parsimony-as-earning-test-outcome + ADR-0050 joint-commitment admission) earns primitive admissions via *cross-tradition convergence* and *operational-pressure tests*, Sahely's argument for the 7-role Fano-grammar is a *closure-uniqueness derivation*:

1. **Pairwise relations cannot achieve closure**: a system requiring resolution of relations beyond pairwise needs more than binary structure (per Sahely Ch 2-3).
2. **Triadic closure suffices and is minimal**: three-way relations can close where pairwise cannot (per Sahely C-2).
3. **The Fano plane is the unique finite structure satisfying triadic closure**: 7 points, 7 lines, each line contains exactly 3 points, each point lies on exactly 3 lines, every pair of points is contained in exactly one line. *"No redundancy. No missing relations. Complete closure."* (per Sahely C-10, p38).

**Note**: this is Sahely's argument; whether the uniqueness claim survives careful mathematical scrutiny is a question for formal review (analogous to the four open questions for Vince in `janus-addressing-sheaf-bridge` §4). The claim is not novel mathematically (the Fano plane has been studied since 1892), but its *application to coordination-grammar* as derivable-from-first-principles is Sahely's contribution.

This is methodologically interesting for Spore canon — it represents a *third earning-test shape* (closure-uniqueness derivation) alongside the two Spore has so far used (cross-tradition convergence + parsimony-as-outcome). Spore has not adopted this earning-test shape. Whether Spore canon could ever admit a primitive on closure-uniqueness grounds is an open question for future canon-method discussion.

### 3.2 [Sahely] 7-role functional-triad design rubric (C/M/X/D/P/R/O × 7 channels)

The seven Sahely-roles (per Sahely C-11, pp39-40):

- **Constraint (C)**: invariants the system must respect
- **Margin (M)**: reserve capacity for absorbing disturbance
- **State (X)**: current configuration of the system
- **Disturbance (D)**: perturbations from outside or inside
- **Perception (P)**: how the system observes its state and environment
- **Regulation (R)**: feedback mechanisms that maintain operation within bounds
- **Options (O)**: degrees of freedom available for response

The 7 functional channels (each is a Fano line — three roles in triadic relationship; per Sahely C-11):

- **(C, M, X) → Geometry of viability**: how constraint, margin, and state co-determine whether the system is in a viable region
- **(X, D, R) → Response channel**: how current state + disturbance + regulation interact to produce dynamics
- **(X, P, O) → Possibility mapping**: how current state + perception + options enumerate what the system can do next
- **(M, O, R) → Adaptive capacity**: how margin + options + regulation determine how flexibly the system can adapt
- **(C, D, O) → Pressure vs possibility**: how constraint + disturbance + options determine where the system is bounded
- **(C, P, R) → Governance**: how constraint + perception + regulation co-implement decision-making
- **(M, D, P) → Early warning**: how margin + disturbance + perception together signal incipient failure

This is Sahely's most concretely applicable design contribution. **[Per Sahely]** any coordination system can be checked for presence of all 7 functional channels; absence of any one is a *structural gap*, not a contingent shortfall. The (M, D, P) early-warning channel is particularly relevant to Spore F6 failure-modes substrate (see §5 nugget 4 below).

**Notable substrate-resonance with already-admitted Spore canon**:
- The "Margin" role (M) maps cleanly to `margin-as-reserve` scope-condition on F9 (admitted via ADR-0089). Spore canon ALREADY has "margin" at the appropriate substrate-layer in F9 maintenance-economics; Sahely's framework names the operational-channel where Margin participates (M-O-R adaptive capacity; M-D-P early warning).
- The "Perception" role (P) maps cleanly to `perception-as-power` scope-condition on F4 (admitted via ADR-0090). Spore canon ALREADY has perception as substrate-of-representation; Sahely's framework names two channels (X-P-O possibility mapping; C-P-R governance) where Perception participates.

This is genuine substrate-resonance — Sahely's 7-role design rubric and Spore canon's admitted scope-conditions are operating on the same substrate-layer with consistent vocabulary, despite arriving via different paths (Sahely's closure-uniqueness derivation vs Spore's cluster-counting + operational-pressure-test). ### 3.3 [Sahely] Octonion-encoding-of-Fano-multiplication

Per Sahely C-13, p53: octonions (the largest normed division algebra) consist of one real unit + seven imaginary units, where each imaginary unit corresponds to a point in the Fano plane. Octonion multiplication is defined by the oriented Fano triads: if (A → B → C) follows the arrow, then A · B = C; reversing introduces sign change. The algebra is non-commutative AND non-associative.

This is Sahely-original *in application* (the mathematical fact that octonions can be defined via oriented Fano triads is canonical; per Baez 2002 *The Octonions* survey). Sahely's contribution is using it as substrate-evidence: *the Fano-plane structure carries deeper algebraic content* (per Sahely C-12, p43), so the 7-role grammar is not arbitrary — it's the surface structure of a non-associative algebra.

**Spore canon has no engagement with octonion algebra**. The cross-domain operational interpretations in §3.6 below don't depend on octonion machinery, so the absence is not a gap for Spore-side adoption purposes.

### 3.9 [Sahely] Fiber-bundle substrate (Ch 6 deep-read addendum)

Sahely's Ch 6 (*Projection and Hidden Coherence: The Fiber Structure of Reality*, pp60-67) is the substrate that bridges the algebraic-substrate layer (Ch 4-5 octonions + associator) and the sheaf-substrate layer (Ch 7). It was not read at high fidelity during Phase 1 extraction; the deep-read post-initial-bridge-note-authoring (2026-05-30) surfaces a substantial Sahely-original contribution that the initial bridge note classified as "PARTIAL" but is in fact RICH (§1 matrix row Restriction-map design updated accordingly).

**§6.1-§6.2 The Problem of Partial Seeing**: Per Sahely, *"No measurement, no model, no perspective captures the full relational structure. What we encounter instead are **projections** — reduced representations that preserve some aspects while discarding others. This is not a limitation of instruments. It is a structural necessity."* The Observable Level (what can be measured / variables / indicators / states) and the Structural Level (full relational configuration / constraints / hidden degrees of freedom) are *conflated* in conventional thinking — "*we assume that what we measure is the system. But this is precisely the error. The observable is not the system. It is a projection of the system.*"

**§6.3-§6.4 Fiber Bundle Minimal Formalization**: Per Sahely, a fiber bundle consists of three elements — a **base space** (what is observed), a **fiber** (what is hidden but necessary), and a **projection** (the mapping from full structure to observable). The interpretive mapping for relational systems:

- **Base Space** = State variables (X) / Measured indicators / Observable outputs
- **Fiber** = *Constraints (C) / Margins (M) / Hidden relational dependencies / Latent capacity and structure*
- **Projection** = Measurement / Modeling / Decision frameworks

**This is a sharp claim**: Sahely explicitly places **Constraints (C) and Margins (M) from the 7-role Fano grammar IN THE FIBER** — they are *not directly observable*. They live in the hidden relational structure. Per Sahely §6.4: *"What we call a 'state' is a projection of a much richer relational configuration."*

**Spore-canon-resonance note**: Spore canon's Bundle α admission of `margin-as-reserve` scope-condition on F9 maintenance-economics (ADR-0089) names Margin operationally at the substrate-layer. Sahely's §6.4 framing says explicitly that Margin lives in the fiber (hidden) not the base space (observable). This composes — Spore admitted margin-as-reserve as substrate-claim; Sahely's fiber-bundle framing names *why* margin is substrate-layer (it's structurally hidden until coherence breakdown). The Phase 3 / Phase 4 capstone ([`sahely-corpus-intake-capstone-2026-05`](sahely-corpus-intake-capstone-2026-05.md) §2) confirms ADR-0089 as the canonical Spore-side resolution of margin-substrate territory; no new canon-pressure follows from §6.4 (the fiber-bundle framing is descriptive substrate-grounding for the existing admission, not a re-opening trigger).

**§6.5-§6.6 Why Projections Fail / The Collapse of Coherence**: Per Sahely, *"Multiple fiber configurations can produce the same projection / Hidden degradation can occur without visible change / Coherence can be lost before indicators shift."* The result: *"Systems appear stable while their underlying coherence is collapsing."* And: *"Failure occurs when the internal relational structure (fiber) degrades; the projection (base space) remains temporarily unchanged. Eventually the projection can no longer be sustained. At that point, collapse appears sudden. But it is not sudden. **It is the visible manifestation of long-hidden structural failure.**"*

**§6.8 The Error of Reification** (load-bearing design discipline): Per Sahely, *"The most common mistake in system design is now clear: Treating projections as if they were the full structure. This is the error of reification."* Examples: *"Treating lab values as the patient / Treating GDP as the economy / Treating indicators as the environment."* Consequences: *"Decisions optimize the projection / The underlying structure is neglected / Coherence degrades / Eventually, the system fails — often in ways that appear surprising. **But the failure was built in from the moment projection replaced structure.**"*

**Spore-canon-resonance — compositional with golden-calf-trap (ADR-0085)**: Both name symbol/structure substitution patterns. *Golden-calf-trap* (Spore-admitted via ADR-0085) is the broader institutional/cultural pattern — substituting a symbol of the substrate (the calf as symbol of god) for the substrate itself (the divine relationship). They compose: reification-error is one operational instantiation of the broader golden-calf-trap pattern; golden-calf-trap subsumes reification-error plus other (non-mathematical-substrate) symbol/substrate substitution patterns; both compose with ADR-0048 substitution-trap as substrate failure-shape.

The Phase 3 capstone closure means this stays at synthesis-bridge-note framing layer (this note) with no separate canon disposition; if operational pressure surfaces post-arc, future canon-discipline practice work could elevate to method-precedent retrospective addendum.

**§6.9 The Emergence of a New Principle**: Per Sahely, *"Viability depends not on the state of observable variables, but on the integrity of the underlying relational structure. This shifts the focus: From measurement → to coherence / From control → to preservation / From variables → to relations."* This grounds the C-6 central claim in fiber-bundle substrate (see §3.8 above).

**§6.10 Toward Diagnostics** (motivates Ch 7 sheaves): Per Sahely, *"If coherence is lost in the fiber before it appears in the base space, then it should be possible to detect failure before it becomes visible."* The need for a *new mathematical tool that can distinguish local consistency from global coherence* is what motivates the introduction of sheaves in Ch 7. **§6.11 Transition** (Sahely's own framing of the chain so far): Per Sahely, *"We now have: A relational grammar / A geometric structure (Fano) / An algebraic diagnostic (associator) / A distinction between observable and hidden structure (fiber). The next step is to unify these into a single framework of consistency. ... The answer lies in a concept that is both simple and profound: Sheaves. ## §5 Design-relevant nuggets for coherence in multi-agent coordination

The substantive design distillation. Ten nuggets, each explicitly attributed.

### Nugget 1 — [Sahely] Structural prerequisites over engineered coherence

Per Sahely C-6 + Ch 1 *Reality Without Objects* + Ch 2 *The Minimal Grammar of Coherence*: *don't try to engineer coherence directly. Engineer the structural prerequisites — triadic closure on relational roles, gluing-discipline across local sections, monitoring of cohomological-obstruction-rise as the early-warning signal. **Why this matters operationally**: most coordination-system designs target coherence as a property to be achieved (e.g., consensus protocols, alignment mechanisms, KPI dashboards). ### Nugget 2 — [Sahely] The 7-role functional-channel design rubric

Per Sahely C-11 (the 7-role grammar): for any coordination system, verify presence of all 7 functional channels:

- **(C, M, X) Geometry of viability** — does the system know its viability region?
- **(X, D, R) Response channel** — does the system have feedback to disturbance?
- **(X, P, O) Possibility mapping** — can the system enumerate available responses?
- **(M, O, R) Adaptive capacity** — does the system have flexibility to adapt?
- **(C, D, O) Pressure vs possibility** — does the system understand where it is constrained?
- **(C, P, R) Governance** — does the system have decision-making coupling constraint + perception + regulation?
- **(M, D, P) Early warning** — does the system sense incipient failure via margin + disturbance + perception?

Missing any channel is a *structural gap*, not a contingent shortfall. **[Per Sahely]** this rubric is universal across multi-agent coordination systems regardless of domain.

**Compositional notes**:
- Composes with Spore's `golden-calf-trap` substitution-trap diagnostic (admitted via ADR-0085): a coordination system that *symbolically* covers all 7 channels but operationally substitutes-the-symbol-for-the-substrate has structurally failed even though the rubric appears satisfied.
- Composes with Johar's "four enabling conditions" framework (ADR-0069 four-enabling-conditions DECLINE-with-trigger; per Bundle α retrospective §6 + DECISION-BRIEF) at design-rubric layer — both are checklists for system-presence-of-substrate.
- The (M, D, P) Early-warning channel is the operational anchor for nugget 4 below.

### Nugget 3 — [Sahely] Triality discipline (rotate state/process/constraint perspectives)

Per Sahely C-14: every coordination view should be expressible from three perspective-rotations — **state-centered** (X-focused: what is the system's configuration?), **process-centered** (R or P focused: what is the dynamics?), **constraint-centered** (C or M focused: what bounds operation?) — *and the three should cohere*. If they don't, you have a perspective-fragmentation problem *before* you have a coordination problem.

**Why this matters operationally**: many coordination disputes are perspective-rotation problems, not substantive disagreements. Two agents may describe the same system in different perspective-centerings and *appear* to disagree when they are looking at the same structure from different sides. The triality discipline says: rotate through all three perspectives systematically; verify they describe the same structure; only then is there a real disagreement to resolve.

This is a *design-discipline contribution* — what an engineer would DO with the framework — rather than a substrate-claim. Spore canon's closest analog is ADR-0058 graph-projections (3-primary: constitutional / commitment / epistemic), but those are projection-types of the same coordination substrate, not perspective-rotations in Sahely's sense.

### Nugget 4 — [Sahely + Bosca-Ghrist + Yokoyama] Cohomological-obstruction as early-warning signal

Per Sahely C-9, p18: *"Early warning signals are not primarily changes in variables but: loss of adaptive capacity, increasing variability, divergence between subsystems, delayed recovery from disturbance. Formally, these correspond to rising cohomological obstruction."*

The composite picture (Sahely + Bosca-Ghrist 2026 + Yokoyama 2026):

- **The signal you want**: rising-obstruction-to-gluing across the system's sheaf structure. Per Bosca-Ghrist: spectral gap of the sheaf Laplacian stabilizes *before* training loss does — so monitoring spectral structure gives earlier-warning than monitoring outputs.
- **The signal you DON'T want to rely on**: metric drift (e.g., KPI decline) — those are *projections of accumulated hidden incoherence* (per Sahely C-8), already-downstream of the structural failure.
- **What this means operationally**: the design-question stops being "what metrics should we monitor and alarm on" and becomes "what spectral / cohomological properties of our coordination sheaf should we monitor for early-warning."

**Compositional notes**:
- Per Sahely's 7-role rubric (Nugget 2), the (M, D, P) early-warning channel is precisely this — margin × disturbance × perception triadic relationship.
- Composes with Spore's F6 failure-modes substrate (per ADR-0075): F6.3 sensor-attestation-evidence-integrity and F6.4 scale-transition would specifically benefit from cohomological-obstruction monitoring as a formal measure of cross-scale gluing-failure.

**Ch 6 fiber-bundle substrate sharpens this further** (deep-read addendum): per Sahely §6.5 *"coherence can be lost before indicators shift"* + §6.6 *"collapse appears sudden but is not sudden; it is the visible manifestation of long-hidden structural failure"* + §6.10 *"if coherence is lost in the fiber before it appears in the base space, then it should be possible to detect failure before it becomes visible."* The fiber-bundle framing gives the substrate-level rationale for *why* cohomological-obstruction is early-warning: failure happens in the FIBER (hidden relational structure) before it propagates to the OBSERVABLE BASE SPACE (measurable indicators). Monitoring observable indicators only catches failure after the projection collapses; monitoring cohomological obstruction (or its spectral proxy via Bosca-Ghrist Fiedler eigenvector) catches failure at the fiber-degradation stage. This is the operational reason monitoring sheaf-structure beats monitoring outputs. See §3.9 fiber-bundle substrate.

### Nugget 5 — [Operator Apr-9 synthesis] Restriction-map design as governance-critical move

### Nugget 6 — [Zhao 2025 + operator inference] Bounded-staleness covenants for federation

Per `zhao-async-nonlinear-sheaf-diffusion` C-1 + C-4: under partial-asynchrony (bounded delay B), nonlinear sheaf diffusion converges to a global minimizer at a periodic linear rate every B+1 steps — *independently of initial condition*. But (per C-4): asynchronous federations converge to *a* coordinated state, but **not necessarily the same coordinated state** a synchronous federation would have produced.

The design implication: a coordination membrane should carry an explicit **B parameter (freshness SLO)** — the maximum staleness the federation tolerates and still converges. This is a *freshness covenant* on the membrane.

**Why this matters operationally**: most coordination-failures in distributed federations come from unstated assumptions about staleness. A federation that converges quickly in synchronous testing may diverge in production where neighbor-state is stale. Naming B explicitly (a) makes the convergence guarantee operational (Zhao's theorem provides one) and (b) makes the staleness-vs-convergence-quality tradeoff explicit (delay-bound is bounded in convergence but the equilibrium itself is delay-sensitive).

**Compositional notes**:
- Composes with Spore's `coordination-substrate` slug (per ADR-0084 admission territory).
- Composes with Spore's `asymmetric-membrane` slug (per ADR-0047 admission): bounded-staleness covenants compose with asymmetric authorization — different membrane-sides can have different B values per authorization-direction.

### Nugget 7 — [JANUS / SHEAF-CAPABILITIES] kNN-as-discovery + sheaf-as-consistency separation

Per `janus-addressing-sheaf-bridge` §3: JANUS introduces three primitives Spore's framing did not have. The deepest is the **separation of discovery from consistency-check**: kNN is fiber-wise discovery primitive (find nearby agents in metric-space); sheaf-overlap is structural consistency-check (does what they say compose with what we say). Two different roles for sheaf structure.

**Why this matters operationally**: many systems conflate "find a relevant agent" with "verify the agent's claims compose with ours." JANUS separates these: discovery happens via metric-axis kNN (find candidates); consistency-verification happens via sheaf-overlap check (does the candidate's claim glue with ours). The discovery operator is *not* sheaf-machinery; the consistency-check is. Conflating them produces systems where high-relevance candidates surface but their claims don't actually compose, OR systems where consistency-checks are too narrow because they only see proximate candidates.

**Caveat per JANUS bridge §3 Where the analogy strains**: kNN is *not* functorial — the k-nearest of x within a smaller cell may differ from (k-nearest within larger cell) ∩ smaller cell. Adopting kNN-style discovery inherits this non-functoriality and requires explicit governance treatment.

### Nugget 8 — [Bosca-Ghrist 2026] Pinned commitments as bidirectional constraint propagation

Per `bosca-ghrist-local-to-global` (Bosca-Ghrist 2026 *Neural Networks as Local-to-Global Computations*): clamping a hidden neuron adds a penalty edge; sheaf diffusion propagates the constraint **bidirectionally** — upstream AND downstream — producing a global equilibrium rather than a local override.

The design analog for Spore coordination: a **pinned commitment** on a coordination sheaf propagates constraints to upstream proposals AND downstream implementations. A committed claim doesn't just constrain its source — sheaf diffusion propagates the constraint through the network.

**Why this matters operationally**: most commitment-tracking systems treat a commitment as a *local* constraint on the committing agent. Bosca-Ghrist's framing says: in a coordination sheaf, a commitment is a *global* constraint that propagates bidirectionally to all dependencies and dependents. Implementations that don't propagate constraint backwards (to upstream agents whose proposals depend on the committed agent's behavior) miss half the work.

**Compositional notes**:
- Composes with Spore's `joint-commitment` slug (per ADR-0050 admission): joint-commitments are *already* irreducibly-joint (not aggregations of individual commitments), so bidirectional propagation is inherent — Bosca-Ghrist gives mathematical substrate for this operational property.

### Nugget 11 — [Sahely §6.8] Error of reification as design discipline

Per Sahely Ch 6 §6.8 (deep-read addendum 2026-05-30): *"The most common mistake in system design is now clear: Treating projections as if they were the full structure. This is the error of reification."* Examples per Sahely: *"Treating lab values as the patient / Treating GDP as the economy / Treating indicators as the environment."* Consequences when this happens: *"Decisions optimize the projection / The underlying structure is neglected / Coherence degrades / Eventually, the system fails — often in ways that appear surprising. **But the failure was built in from the moment projection replaced structure.**"*

**Why this matters operationally**: most coordination-system *measurement architectures* are reification-error architectures by default. Instrumenting a coordination system with metrics, dashboards, and KPIs is *building a base-space-only view*; without explicit fiber-tracking (cohomological-obstruction monitoring per Nugget 4; restriction-map fidelity per Nugget 5), the measurement architecture itself enforces reification. Design moves accordingly: every metric needs an accompanying "what fiber-content is this metric a projection of, and what does the projection discard?"; every dashboard needs a fiber-degradation early-warning channel (per the (M, D, P) early-warning channel of the 7-role rubric, Nugget 2); every decision-framework needs explicit treatment of "what we are optimizing IS the projection, not the structure being projected."

**Compositional notes**:
- Composes with Spore-canon-admitted `golden-calf-trap` (per ADR-0085) but is distinct. Golden-calf-trap is the broader institutional/cultural pattern — substituting a symbol of the substrate for the substrate itself (the calf as symbol of god). Reification-error is the specifically-mathematical-substrate variant — substituting projections (observable variables) for the structure-being-projected (fiber-relational-configuration). They compose: reification-error is one operational instantiation of the broader golden-calf-trap pattern; golden-calf-trap subsumes reification-error plus non-mathematical-substrate substitutions (e.g., ceremony-for-substance in governance; certification-for-skill in labor; KPI-for-goal in strategy).
- Composes with Spore-canon-admitted `recursive-audit-method` (per ADR-0085): the recursive-audit asks "did I just substitute symbol for substrate?" — for mathematical-substrate substitutions, the question sharpens to "did I just treat a projection as the full structure?" The two together form a discipline: golden-calf-trap names the failure-class; reification-error names the mathematical-substrate sub-class; recursive-audit catches both.
- Composes with Nugget 9 (shift from control-of-variables to preservation-of-relational-coherence-under-constraint): the variable-vs-relational-coherence shift is precisely the reification-error correction at the design-discipline layer.

**Phase 3 closure resolution**: Phase 3 + Phase 4 closed 2026-05-30 with no separate reification-error canon disposition. Per Phase 3 capstone §2: `golden-calf-trap` ≡ shape-of ADR-0048 `substitution-trap` (not equivalent-to); reification-error is the mathematical-substrate sub-shape within that family.
