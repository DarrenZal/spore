## 2. C-claims (verbatim from extraction record)

All quotes verbatim from the extraction record §"Verbatim key claims (~14 claims from pages 1-14)". RID `orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory`; page anchors per extraction record.

- **C1** [anchor: §Abstract · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p9] **LOAD-BEARING — minimal structural thesis:** "This work advances a minimal structural thesis: living systems are bounded, history-sensitive dynamical systems whose continued existence depends on preserving connected viable futures under finite constraint."

- **C2** [anchor: §Abstract · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p9] Topological formalism: "Persistence requires sustained interiority within a viability set *K*. Repeated imbalance encodes structural deformation, producing curvature, tipping points, hysteresis, and basin multiplicity. Reachable future space 𝒱(s) defines optionality. Control processes function to preserve or expand this space."

- **C3** [anchor: §Abstract · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p9] **LOAD-BEARING — central evaluative question:** "The central evaluative question becomes: does a given action widen or narrow the space in which the future remains possible?"

- **C4** [anchor: §Executive Summary · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p10] Six core claims: "1. Every living system operates within a bounded viability set *K*. 2. Persistence requires remaining inside this boundary under finite constraint. 3. Repeated imbalance encodes structural deformation (entrenchment). 4. Deformation reshapes topology, producing tipping points and hysteresis. 5. Reachable future space 𝒱(s) defines optionality. 6. Value corresponds to preserving or expanding connected viable futures."

- **C5** [anchor: §Executive Summary · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p10] Applied framings: "Health is sustained interiority with sufficient margin and corridor width. Chronic disease is basin narrowing under accumulated deformation. Economic instability emerges from curvature steepened by debt, inequality, and volatility. Governance functions as cross-scale control architecture preserving global viability."

- **C6** [anchor: §Executive Summary · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p10] Triadic unification: "Ontology, epistemology, and axiology are not separate disciplines but dynamically coupled phases of viability preservation: Being is bounded persistence. Knowing is constraint-sensitive forecasting. Value is preservation of connected futures."

- **C7** [anchor: §Executive Summary · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p10] Non-ideological framing: "The framework does not prescribe ideology. It provides structural criteria. A policy, institution, or intervention is viability-aligned if it widens connected viable space across temporal and cross-scale horizons."

- **C8** [anchor: §Executive Summary · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p10] **LOAD-BEARING — central maxim:** "Preserve the space in which the future remains possible."

- **C9** [anchor: §I · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p11] Viability set + margin: "This region — the viability set — separates states compatible with persistence from those that terminate it. To exist, such a system must remain inside this boundary. Persistence therefore depends on margin: the slack between current conditions and the boundary of collapse. When margin narrows, fragility increases. When margin disappears, tipping becomes inevitable."

- **C10** [anchor: §I · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p12] **LOAD-BEARING — memory-as-deformation:** "Repeated imbalance — when demand exceeds replenishment — encodes structural deformation. This deformation alters the topology of the viable region itself. Basins narrow. Curvature steepens. Tipping points emerge. Recovery becomes more difficult than decline. Memory, in this framework, is **not recollection. It is deformation**."

- **C11** [anchor: §II · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p12] Triadic collapse: "Ontology concerns the existence of the viability boundary. Epistemology concerns forecasting constraint to remain within it. Axiology concerns action that preserves reachable futures. The three domains collapse into structural unity. Being is sustained interiority under constraint. Knowing is constraint-sensitive modeling. Value is preservation of connected viable space."

- **C12** [anchor: §VI · orn:source:bsahely-2026-02-12-unifying-grammar-of-viability-constraint-memory · pdf-p14] **HIGHEST-LOAD-BEARING — four-element grammar:** "The grammar is simple. Constraint defines the field. Memory deforms it. Control navigates it. Value preserves it. The future exists only inside that structure."

## 4. Substrate-resonance map (descriptive)

This reads the paper's pp 9-14 substrate against Spore's resolved post-Bundle-α canon (14 foundation docs / 9 primitives / 4 cross-cutting doctrines / 2 modes / 2 properties; concepts-yaml v24; 40 canon-decisions through ADR-0090). Descriptive only.

### 4.1 Four-element grammar ↔ Spore coordination grammar (cross-layer, not 1:1)

C12 — *"Constraint defines the field. Memory deforms it. Control navigates it. Value preserves it."* — is a four-element grammar at the **metaphysical/philosophical** layer. Spore's grammar is **operational** (9 coordination primitives + 4 doctrines + 2 modes + 2 properties). These are adjacent but cross-layer, exactly as the Phase-2 Maturana anchor established for Sahely's 8-primitive diagnostic grammar. The loose alignment the extraction record suggests (Spore Field ≈ Sahely Constraint; Spore Reproduction ≈ Sahely Memory + future-preservation; Spore Signal/Intent/Commitment loop ≈ Sahely Control; Spore doctrines ≈ Sahely Value) is a *compositional* reading — Sahely's grammar names a substrate Spore's operational grammar must not violate — not a primitive-roster equivalence. No canon-shift candidate.

### 4.2 Value = preservation of connected viable futures ↔ life-value-doctrine (ADR-0086)

C6/C8's *"Value is preservation of connected futures"* and *"Preserve the space in which the future remains possible"* sit in the canon-shape slot now occupied by `life-value-doctrine` — the **fourth cross-cutting doctrine** (sibling to `reproductive-commoning` / `boundary-commoning` / `care-commoning`), admitted at ADR-0086 from the McMurtry life-value / universal-human-life-necessities lineage. The convergence is real and **already resolved**: ADR-0086 expanded the canon-object-class doctrine count 3→4. This paper supplies the topology-formal articulation of the same doctrine (future-option-space preservation), but it is one source within one author-corpus; it adds no new canon-pressure beyond the closed decision. Framing-note-only.

### 4.3 Widen-or-narrow test + flow-optimization-while-topology-collapses ↔ golden-calf-trap (ADR-0085)

C3/C7's evaluative gate (*"does a given action widen or narrow the space in which the future remains possible?"*) and the extraction record's note that flow-optimization-while-topology-collapses *is* the Johar substitution-trap in topological form name a trap-shape. ADR-0085 admitted `golden-calf-trap` as the canonical anchor for that shape — explicitly the **shape-of** ADR-0048 `substitution-trap`, not equivalent-to it — plus `recursive-audit-method` as the self-applying discipline. The widen-or-narrow test functions as a *concrete diagnostic instance* of recursive-audit-method applied to an action. Resolved by Bundle α; framing-note-only.

### 4.4 Margin / entrenchment / basin-narrowing ↔ margin-as-reserve (ADR-0089) + failure-modes (F6)

C9/C10's margin-as-slack-before-collapse and memory-as-structural-deformation map onto two resolved decisions. (i) ADR-0089 scope-conditioned **margin-as-reserve** onto F9 maintenance-economics — margin/reserve/resilience as the slack a viable system must hold; Sahely's margin-as-corridor-width is the topology-layer articulation. Neither requires a shift; both are already canon. Framing-note-only.

### 4.5 Persistence ≠ value ↔ structural-legitimacy (ADR-0042) + memory-as-deformation ↔ rule-in-use / Holon-coupling

C1/C7 insist persistence-under-constraint is not itself the criterion — value is whether the action *widens* viable space. This parallels `structural-legitimacy`'s discipline that operational persistence is not legitimacy (ADR-0042 promoted it to foundation level). Separately, C10's *"Memory… is not recollection. It is deformation"* — history encoded as structural change to the system's own viable region — resonates with two substrate decisions: (a) ADR-0046 `rule-in-use` (operational conservation, not formal-statement conservation, as the locus of identity); and (b) the organism-medium structural-coupling axis underneath ADR-0050 Holon-irreducibility + ADR-0062 Membrane-as-self-produced. All already-canonical; framing-note-only reinforcement from an adjacent (dynamical-systems) tradition.
