## Context

`ADR-0045 care-cross-cutting-doctrine` (`2026-04-22` Phase 3b.1 Option F; commit landed under canon-rebuild arc) admitted `care-commoning` as third cross-cutting doctrine sibling to `reproductive-commoning` (ADR-0002) and `boundary-commoning` (ADR-0003). ADR-0045 §Context + §Operational-earning + §Evidence cite a care-ethics lineage cluster: Held three-sense (labor + disposition + relation per *The Ethics of Care* 2006); Tronto four-phase (attentiveness → responsibility → competence → responsiveness + caring-with per *Caring Democracy* 2013); Kittay nested-dependency (per *Love's Labor* 1999); Federici invisibilisation critique (per *Caliban and the Witch* 2004). Post-ADR-0086 (life-value-doctrine 4th cross-cutting doctrine 2026-05-25), the canon-object-class inventory expanded from 3 → 4 doctrines; care-commoning remains canonical at doctrine layer.

The Sahely corpus Phase 2 (closure 2026-05-22) surfaced a substantive additional tradition-cluster that ADR-0045 does NOT currently cite at substrate-evidence layer: **Sahely-Maturana school articulating care-as-structural-coupling** — Maturana / Verden-Zöller / Bunnell / Dávila Yáñez lineage as documented in Sahely 2026-05-21 *Toward a Maturana-Informed Viability Grammar* (W1.1 substrate at `spore.connection.sahely-maturana-viability-grammar`) + Sahely 2026-05-22 *Biology of Living Coordination* (W1.2 substrate at `spore.connection.sahely-biology-of-living-coordination`), substrate-strengthened at clinical-encounter scale by W3.3 systems-immunology + W4.3 medicine-of-living-coherence per DECISION-BRIEF §17.4.

The Sahely DECISION-BRIEF §5 evaluated this surfaced substrate against three possible Spore-canon dispositions:

- **(i) NEW slug admission**: rejected — `care-commoning` slug already exists; no new vocabulary needed; would be category-error (duplicating existing slug under different name).
- **(ii) NEW doctrine admission**: rejected — care-commoning doctrine already at 4-doctrine-count post-ADR-0086; Maturana-school substrate articulates the SAME operational concern (care-as-foundational-relational-practice) through a different tradition-angle (structural-coupling formalism vs asymmetric-relational practice).
- **(iii) Scope-condition substrate-strengthening to existing ADR-0045**: ratified per DECISION-BRIEF §5.2 honest-rigor cluster-counting + §17.4 substrate-strengthening + §17.8 (4) operator final disposition.

Operator selected (iii). This ADR executes the disposition.

**Why scope-condition is the cleanest shape**: the Sahely-Maturana cluster is a substrate-evidence enrichment, not a category-shift. ADR-0045's doctrine territory (care-as-asymmetric-relational-practice operating across primitives via doctrine-lens treatment, not paraphrase-able into Spore's symmetric primitive grammar) remains unchanged. What changes is the substrate-evidence base ADR-0045 cites: Maturana's "love...as the relational domain in which the other arises as legitimate in coexistence, is not sentimental but foundational" (Sahely W1.1 C-6 verbatim) provides a foundational-relational reading that complements the Held/Tronto/Kittay/Federici asymmetric-relational reading. Both clusters articulate care-as-foundational-relational-practice through which structural-coupling is sustained — different tradition-angles of the same operational concern per ADR-0064 honest-rigor.
