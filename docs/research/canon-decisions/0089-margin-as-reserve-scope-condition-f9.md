# ADR-0089 — Margin-as-Reserve scope-condition substrate-strengthening to F9 maintenance-economics (Sahely-Margin + Resilience-theory + Antifragility tradition-anchors)

## Status

draft (authoring under `~/.claude/plans/adr-0089-margin-as-reserve-scope-condition-f9.md`; atomic-bundle 2-commit ceremony per Bundle α discipline)

## Context

`F9 maintenance-economics` (`docs/foundations/maintenance-economics.md`; admitted via ADR-0079 `2026-04-26` Phase 4 Tier C SECOND admission) carries maintenance-economics foundation-doctrine across eight categories (§4.1 Reproductive-Labor Visibility … §4.8 Cross-Federation Portability), with the `reproductive-infrastructure` + `compensation-pattern-layer` derived-glossary slugs as canonical anchors. F9's load-bearing substrate is the 5-citation reproductive-labour invisibilisation cluster (Federici / Mies / Bresnihan / Bhattacharya / Gibson-Graham) at `docs/foundations/federation-protocol.md:28`. The reserve substrate — the slack / buffer / adaptive-capacity that lets a coordination system absorb disturbance without losing coherence — is implicit in F9's reproductive-infrastructure doctrine (§4.5 Infrastructure-Economics acknowledges substrate thinness; §6 Open Questions surfaces deeper articulation as future foundation-doctrine elaboration) but is NOT currently grounded in a cross-tradition substrate-evidence cluster.

The Sahely corpus Phase 2 (closure 2026-05-22) surfaced a substantive cross-tradition cluster that F9 does NOT currently cite at substrate-evidence layer: **margin-as-reserve / slack-as-resilience as NOT-inefficiency** — Sahely *Architecture of Viability* §2.2 Margin (W2.3 substrate at `spore.connection.sahely-architecture-of-viability`) + Resilience-theory (Holling / Walker / Folke) + Taleb antifragility, substrate-strengthened at the organism-immune scale by W3.3 systems-immunology allostatic-load (McEwen / Sterling-Schulkin) per DECISION-BRIEF §17.4.

The Sahely DECISION-BRIEF §11 + §12.4 evaluated this surfaced substrate against three possible Spore-canon dispositions:

- **(i) NEW slug admission** (`reserve-margin` / `slack-as-resilience`): rejected — F9's `reproductive-infrastructure` slug already covers the reserve substrate; a new slug would duplicate territory. Rejected DESPITE the cluster-count (3 FULL) being sufficient for a derived-glossary slug, per parsimony-as-earning-test-outcome.
- **(ii) NEW primitive admission** (margin as a Spore coordination-grammar primitive): rejected — the margin-as-foundation-primitive reading is THIN (Sahely-only at synthesis layer per W2.3 §4.5 (b)); the cross-tradition support is for margin/slack/reserve at the engineering-resilience layer, not for margin-as-canonical-foundation-primitive-of-coordination-grammar.
- **(iii) Scope-condition substrate-strengthening to existing F9**: ratified per DECISION-BRIEF §12.4 honest-rigor cluster-counting + §17.4 W3.3 substrate-strengthening + §17.8 operator final disposition.

Operator selected (iii). This ADR executes the disposition.

**Why scope-condition is the cleanest shape**: the Sahely-Margin + Resilience-theory + Antifragility cluster is a substrate-evidence enrichment of F9's existing reserve-substrate doctrine, not a category-shift and not new vocabulary. F9's doctrine territory (reproductive-infrastructure as first-order coordination content; maintenance-economics canon-legibility without prescribing compensation protocols) remains unchanged. What changes is the substrate-evidence base: Sahely's "Margin is not inefficiency... systems designed only for maximum throughput... consume their own buffers... increase performance by reducing resilience" (W2.3 C16 verbatim) + the Resilience-theory and Antifragility clusters provide a cross-tradition grounding for the doctrinal commitment that reproductive-infrastructure reserve is first-order coordination content, complementing the Federici/Mies/Bresnihan/Bhattacharya/Gibson-Graham invisibilisation-critique reading with a resilience-engineering / viability reading. Both articulate why reserve substrate must be canon-legible and must not be optimized away — different tradition-angles of the same operational concern per ADR-0064 honest-rigor.

### Honest-rigor cluster-counting: scope-condition over slug DESPITE sufficient cluster-count

Per ADR-0081 method-precedent: cluster-counting is verdict-neutral audit, not decline-mechanism. ADR-0089 specifically: 3 FULL clusters (Sahely-Margin / Resilience-theory Holling-Walker-Folke / Taleb-antifragility) + Lean-vs-resilient operations PARTIAL. This count EXCEEDS both the ≥2-cluster derived-glossary threshold AND the ≥3-cluster threshold — it would *support* a `reserve-margin` / `slack-as-resilience` slug. The scope-condition shape is nonetheless the cleaner disposition because F9's existing `reproductive-infrastructure` slug already covers the reserve substrate; a new slug would duplicate territory. This is **parsimony-as-earning-test-outcome** (ADR-0048; `feedback_parsimony_elegance_dual_discipline.md` — "would fill a beautiful gap" is rejected as admission argument). W2.3 §4.5 self-anticipates: "enrichment of `reproductive-infrastructure` slug semantics OR scope-condition F9 doctrine; new slug unlikely under honest-rigor parsimony."

**This is a distinct method-precedent from ADR-0088**: ADR-0088 declined slug-admission because only 2 clusters surfaced (below the slug threshold → scope-condition *by necessity*). ADR-0089 declines slug-admission DESPITE 3 clusters (above the slug threshold → scope-condition *by parsimony / existing-slug-coverage*). The two cases together demonstrate that scope-condition is a disposition reachable both from below the slug threshold (insufficient evidence) and from above it (sufficient evidence but existing-slug-coverage makes a new slug redundant). New precedent for the Bundle α retrospective: **scope-condition-chosen-over-slug-despite-sufficient-cluster-count.**

The margin-as-foundation-primitive reading (margin as a Spore coordination-grammar primitive) is THIN (Sahely-only at synthesis layer per W2.3 §4.5 (b)) and is explicitly NOT claimed. The cross-tradition support is RICH at the engineering-resilience layer (which grounds the reserve-substrate-strengthening) but THIN at the coordination-grammar-primitive layer (which would be required for primitive admission). Scope-condition honors this asymmetry.
